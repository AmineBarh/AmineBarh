### About

I build systems end-to-end — from sensor firmware on ESP32 to YOLO vision models and containerised backends. Currently finishing a 4th-year engineering degree at ESIEA Paris with a focus on ML, computer vision, and embedded IoT.

- **Now:** Internship on BeeSafe — connected beehive monitoring + YOLOv11 bee detection
- **Looking for:** 6-month final-year internship starting **February 2027**
- **Interests:** Computer Vision · Embedded Systems · MLOps · Full-stack
